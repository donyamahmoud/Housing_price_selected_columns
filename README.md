# Housing Price Prediction 🏡

This project focuses on building a Machine Learning model to predict housing prices based on various features using Python and Scikit-Learn.

## 🛠️ Tech Stack
* *Language:* Python
* *Libraries:* Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* *Environment:* Google Colab

## 📊 Project Workflow
1. *Data Preprocessing & Cleaning:* Handling missing values and preparing categorical features using pd.get_dummies().
2. *Exploratory Data Analysis (EDA):* Visualized feature distributions and correlation heatmaps to understand relationships in the dataset.
3. *Model Training:* Built and trained a Linear Regression model to predict house prices.
4. *Evaluation:* Evaluated the model performance to ensure accuracy.

## 🚀 How to Run
1. Clone the repository.
2. Open the Jupyter Notebook or Google Colab link provided.
3. Run the cells sequentially to see the data analysis and predictions.
